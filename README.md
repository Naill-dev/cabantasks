# 📋 Kanban Board

A modern and responsive **Kanban Board** web application built with **HTML, CSS, and Vanilla JavaScript**. The application allows users to manage tasks efficiently using a simple drag-and-drop interface while keeping data stored locally in the browser.

---

## 🚀 Features

- ✅ Dynamic rendering of tasks from a JavaScript array
- ✅ Create, edit, and delete tasks (CRUD operations)
- ✅ Drag and drop tasks between columns
- ✅ Persistent data storage with LocalStorage
- ✅ Search tasks by keyword
- ✅ Filter tasks by priority
- ✅ Protection against XSS attacks using safe rendering
- ✅ Duplicate task prevention
- ✅ Responsive design for desktop and mobile devices
- ✅ Keyboard accessibility support

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- HTML5 Drag and Drop API
- LocalStorage

## ⚙️ Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/kanban-board.git
```

2. Open the project folder:

```bash
cd kanban-board
```

3. Open `index.html` in your browser or use a local development server.

---

## 💡 Functionality

- Add new tasks with title, description, and priority.
- Edit or delete existing tasks.
- Move tasks between **To Do**, **In Progress**, and **Done** columns using drag and drop.
- Search tasks instantly by title.
- Filter tasks based on priority.
- Automatically save all changes in LocalStorage.
- Prevent duplicate tasks and safely render user input.
